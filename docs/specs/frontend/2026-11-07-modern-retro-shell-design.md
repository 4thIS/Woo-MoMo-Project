### 지금 무엇이 문제인가

| 현상 | 원인 |
|---|---|
| 상단 바가 오른쪽에만 붙어 있고 왼쪽이 완전히 비어 있다 | `TopBar.vue`가 `justify-content: flex-end` 하나로 끝난다. 브랜드도 현재 단계 표시도 없다 |
| 항목 다섯이 같은 무게로 늘어선다 | 관리자 · 모모 프리미엄 · 티켓 · 보관함 · 내정보 — 상태와 이동과 판매가 한 줄에 평평하다 |
| 720px 아래에서 바가 두 줄로 접히고 `--topbar-h`가 64 → 96px로 **바뀐다** | 아래 화면 전부가 그 숫자를 믿고 비켜 서 있어, 한 값이 화면 폭에 따라 흔들린다 |
| 긴 약관·안내문까지 픽셀 글꼴이라 읽기 어렵다 | 본문용 글꼴 역할이 나뉘어 있지 않다 |
| 모든 것에 2px 액자가 둘러져 있어 위계가 없다 | `--win-border`를 면 구분에도 쓰고 있다 |

## 1. 목표 · 비목표

### 목표

- **색 토큰을 하나도 바꾸지 않고** 화면을 2026년 것으로 보이게 한다. 바꾸는 것은 간격 · 위계 · 정렬 · 글꼴 역할뿐이다.
- 상단 바의 **떠 있는 성격을 지킨다.** 판도 선도 없이 글자만 떠 있는 지금의 연출이 기본값이다.
- 상단 바 항목을 **상태**(프리미엄 · 티켓)와 **이동**(보관함 · 내정보)으로 가른다.
- `--topbar-h`를 **64px로 고정**한다. 화면 폭에 따라 바뀌지 않게 한다.
- 긴 글(약관 · 안내문 · 리포트 피드백)만 산세로 넘겨 가독성을 올린다.

### 비목표 (이번엔 안 함 / 후속)

- **면접실과 면접관은 손대지 않는다.** 무대 · 책상 · 조명 · 초상 · 말풍선 · 출근 애니메이션 전부 픽셀 그대로다.
- 둥근 모서리를 쓰지 않는다. `border-radius`는 어디에도 넣지 않는다.
- 왼쪽 세로 레일(시안 C안)은 채택하지 않는다 — 모든 화면의 가로 기준을 다시 잡아야 해 이번 범위 밖이다.
- 로고 워드마크의 글꼴(Galmuri11)은 그대로다.

## 3. 접근 제어 / 제약

### 지키는 다섯 (레트로)

1. **모서리는 0.** `border-radius`를 쓰지 않는다.
2. **하드 그림자.** 흐리게 만들지 않는다. `5px 5px 0` → `3~4px 3~4px 0`으로 줄이기만 한다.
3. **글로우.** 켜진 램프의 `box-shadow: 0 0 7px`은 CRT의 핵심이라 남긴다.
4. **주사선과 별 배경.**
5. **숫자와 라벨은 픽셀 글꼴.** 티켓 수, 용량, 시간, 측정값.

### 바꾸는 셋 (모던)

1. **여백** — 상단 바 항목 사이 14 → 20px, 바 안쪽 20 → 26px.
2. **위계** — 테두리는 **누를 수 있는 것**에만. 면은 배경 밝기 차이(`--bg` / `--win` / `--raise`)로 가른다.
3. **정렬** — 왼쪽 묶음과 오른쪽 묶음이 같은 기준선에 선다.

### 상단 바의 두 상태

| 상태 | 언제 | 모양 |
|---|---|---|
| 떠 있음 (기본) | 히어로가 화면에 있는 동안 | 배경 · 테두리 없음. 오른쪽 글자만. 글자마다 `text-shadow: 1px 1px 0 var(--ink)` |
| 판 깔림 | 히어로를 벗어난 뒤 | `--dock`(`#12152fe6`) 배경 + 아래 1px `--raise`. 왼쪽에 워드마크 + 현재 단계가 들어온다 |

- 전환은 **히어로 끝에 둔 보이지 않는 표식**을 `IntersectionObserver`로 지켜보고 클래스를 붙이는 방식이다. `scrollTop`을 읽지 않고, 휠을 가로채지 않는다 — 선행 spec에서 못 박은 원칙 그대로다.
- **높이는 두 상태 모두 64px**이다. 상태가 바뀌어도 아래 화면이 밀리지 않는다.
- 면접 화면처럼 바탕이 밝은 곳에서는 처음부터 판을 깐다.
- 맨 위에서 왼쪽을 비워 두는 것은 의도다 — 히어로 가운데에 이미 큰 이름이 있다. 작은 이름을 또 둘 이유가 없다.

### 상단 바 항목 배열 (로그인 상태)

```
(왼쪽: 판 깔린 뒤에만)  ■ 모두의 모의면접  │ 준비
(오른쪽)  ●프리미엄   [🎫 3]  │  보관함   내정보
             상태              이동
```

- **상태 묶음** — 프리미엄 램프(켜짐이면 글로우), 티켓 수. 티켓 숫자는 픽셀 글꼴로 15px.
- **이동 묶음** — 보관함, 내정보. 세로줄 1px로 가른다.
- **관리자 링크는 내정보 안으로 넣는다.** 쓰는 사람이 둘뿐이라 평소에 보일 이유가 없다.
- 티켓의 `🎟` 이모지를 **픽셀 아이콘**으로 바꾼다 — 지금 여기만 기종에 따라 모양이 다르다.
- 비로그인은 지금처럼 `로그인` 버튼 하나다(민트 `--accent-2`, 노랑은 쓰지 않는다).
- 좁은 화면(≤720px)에서는 보관함·내정보의 **글자를 떼고 아이콘만** 남겨 한 줄을 유지한다. 아이콘만 남는 버튼에는 `aria-label`을 반드시 단다.

### 글꼴 역할

| 글꼴 | 쓰는 곳 |
|---|---|
| `--font-display` (Galmuri11) | 로고, 큰 제목, 버튼 |
| `--font-mono` (GalmuriMono11) | 라벨, 측정값, 코드, **모든 숫자** |
| `--font-read` (신규, 산세) | 긴 본문만 — 약관, 안내문, 리포트 피드백, 답변 원문 |

- 신규 토큰 **셋**만 만든다: `--font-read`, `--lh-read`(1.8), `--gap-card`(32px). 색 토큰은 손대지 않는다.
- `--font-read`의 실제 글꼴은 Pretendard를 1순위로, 시스템 한글 산세를 폴백으로 둔다. 웹폰트를 새로 내려받게 되므로 용량과 로딩 시점을 plan에서 정한다.

## 4. 인터페이스 계약

| 함수 · 토큰 · 선택자 | 접근 | 설명 |
|---|---|---|
| `--topbar-h` | internal | **64px 고정.** `@media (max-width: 720px)`의 96px 재정의를 삭제한다 |
| `--font-read`, `--lh-read`, `--gap-card` | internal | 신규. `tokens.css`에만 정의한다 |
| `TopBar.vue`의 `.docked` | internal | 판이 깔린 상태. `IntersectionObserver`가 붙이고 뗀다 |

## 5. 영역별 영향

- frontend: `components/TopBar.vue`(배열·두 상태), `styles/tokens.css`(토큰 3개 추가, `--topbar-h` 재정의 삭제), `styles/base.css`(테두리·그림자 규칙 정리), 새 픽셀 티켓 아이콘 1개, 관리자 링크를 `MeModal`로 이동.
- backend: 없음.
- deploy / finetune: 없음. (`--font-read` 웹폰트를 자체 호스팅하면 `deploy/` 영향이 생긴다 — plan에서 결정)

## 6. 무회귀 · 롤아웃

- 계약 변경이 없어 단독 배포 가능하다.
- **`--topbar-h`가 96 → 64로 줄어드는 영향**이 가장 넓다. 이 토큰을 읽는 모든 화면(랜딩 · 준비 · 리포트의 머리글)을 좁은 폭에서 눈으로 확인해야 한다.
- 관리자 링크가 상단 바에서 사라진다. `/admin`은 주소로 직접 들어가도 되지만, 내정보 안에 들어간 것을 cw에게 알린다.
- 배포 순서: 작업 PR → `dev` → demomo 확인 → `dev → main`.

## 8. 성공 기준

- 랜딩 맨 위에서 상단 바에 **배경도 테두리도 없다.** 별 배경 위로 글자만 떠 있고, 그 글자가 읽힌다.
- 히어로를 지나면 판이 깔리고 왼쪽에 이름이 들어온다. 그때 아래 내용이 **밀리지 않는다.**
- 창 폭을 1440 → 390px로 줄이는 동안 바가 **한 줄을 유지**한다.
- 390px에서 보관함·내정보가 아이콘만 남고, 화면 낭독기가 각각의 이름을 읽는다.
- 약관 전문을 열었을 때 본문이 산세로 나오고 줄간이 1.8이다. 로고와 버튼은 여전히 픽셀 글꼴이다.
- 코드베이스에 `border-radius` 검색 결과가 0건(기존 포함).
- 프론트 게이트 전부 통과.
