# 준비 화면 레이아웃 — 기다리는 동안 입력이 끝나게 (spec)

- 생성일시: 2026-11-07
- 수정일시: 2026-11-07 (벤 성향 설정 추가)

## 0. 배경 · 위치

전체 설계서 6절 "준비 화면"에 해당한다. 랜딩에서 면접관·모델을 고르고 넘어온 뒤, 모델을 내려받으면서 지원 정보와 이력서를 받는 화면이다.

개편 시안(승인 완료): https://claude.ai/artifact/7q3VdUDuQdVcgpyKHdWLVd — 아트보드 `준비 A — 왼쪽 상황판 · 오른쪽 입력`, `준비 — 입력 칸과 시작 영역`

개편 순서에서 **3번**. 선행: 스크롤 애니메이션 철거, 모던 레트로 껍데기.

> **2026-11-07 개정.** cw가 `benSettings`(벤 성향 다섯 축)를 `POST /api/premium/interviews`에 additive로 올렸는데(`docs/specs/backend/2026-11-07-ben-settings-design.md`) **화면이 없어 아무도 쓸 수 없다.** 그 화면이 들어갈 곳이 이 준비 화면이라 이 spec에 함께 넣는다. 시안 아트보드 `벤 성향 B — 게임 옵션 화면`(승인 완료).

### 지금 무엇이 문제인가

| 현상 | 원인 |
|---|---|
| 모델 3.1GB를 받는 **4분이 빈 시간**이다 | 진행 창과 입력 창이 서로 다른 `.snap` 섹션이다. 입력하려면 한 화면을 내려가야 한다 |
| 이력서 넣는 방법 넷이 늘 세로로 쌓여 있다 | 저장본 목록 · 드롭존 · 양식 버튼 · 붙여넣기가 전부 펼쳐진 채다. 양식까지 열면 창이 두 배가 된다 |
| 가장 중요한 `면접 시작` 버튼이 안내문 여섯 줄 아래에 묻힌다 | 면접관 칩 · 힌트 · 벤 안내 · 목소리 동의 · 체크리스트 · 목소리 대기 안내가 세로로 줄줄이 선다 |
| 2단계(지원 정보 → 이력서) 화살표 전환이 번거롭다 | 칸이 넷 이하인데 단계를 나눴다 |

면접 전 가장 큰 이탈 요인이 이 4분이다(작품 설명 6절). 그 시간에 할 일을 주는 것이 이 spec의 핵심이다.

## 1. 목표 · 비목표

### 목표

- 모델을 받는 **동안** 지원 정보와 이력서를 다 넣을 수 있게 한다. 기다림과 입력을 한 화면에 둔다.
- 시작 버튼이 왜 아직 비활성인지 **버튼 바로 위에서** 보이게 한다.
- 이력서 입력 방법 넷을 접어 세로 길이를 줄이고, 동시에 "넷이 있다"는 것을 알린다.
- 시작 영역을 세 덩이로 정리해 시작 버튼을 눈에 띄는 자리에 둔다.
- **벤 성향 다섯 축을 고를 수 있게 한다.** 지금은 서버만 있고 화면이 없어 쓰이지 않는 기능이다.

### 비목표 (이번엔 안 함 / 후속)

- **진행바와 면접관 출근 애니메이션은 그대로 쓴다.** `PixelProgress`와 그 안의 장면을 바꾸지 않는다. 자리만 옮긴다.
- 상단 진행 띠로 접는 안(시안 B)은 채택하지 않는다.
- 이력서 추출 로직(`services/pdf.ts`), 모델 내려받기 로직(`stores/model.ts`)은 손대지 않는다.
- 면접관 바꾸기 패널(`InterviewerPicker`)의 동작은 그대로다.
- **벤 성향의 프리셋·저장**은 하지 않는다(cw의 백엔드 spec도 범위 밖에 뒀다). 고른 값은 이 면접에만 쓰고 다음 면접에 기억하지 않는다.
- **리포트·보관함에 성향값을 적지 않는다.** 같은 이유로 범위 밖이다.

## 2. 데이터 · 계약 (있다면)

스키마를 **바꾸지 않는다.** 이미 배포된 선택 필드를 **쓰기 시작할** 뿐이다 → lockstep 불필요(서버가 먼저 나가 있다).

- `POST /api/premium/interviews`의 `benSettings`(선택, additive, 2026-11-07) — `docs/API.md` 참조.
  - 다섯 칸: `warmth` · `followUp` · `questionMix` · `difficulty` · `companyWeight`. 각 3단계.
  - **일부만 보내도 된다.** 빠진 칸은 서버가 기본값으로 채운다.
  - 정해진 값이 아니거나 모르는 키면 `422 invalid`.
- `backend/data/manifest.json` 변경 **없음**.

## 3. 접근 제어 / 제약

### 채택 배치 — 왼쪽 상황판 · 오른쪽 입력

```
┌──────────────────────────────────────────────────────────────┐
│  (떠 있는 상단 바)                            보관함  내정보  │
├──────────────┬───────────────────────────────────────────────┤
│  면접관이     │  어디에 지원하시나요?        면접관 데이빗 [바꾸기] │
│  출근하는 중   │  ─────────────────────────────────────────── │
│  [출근 장면]   │  분야  [IT·개발] 디자인 경영…                 │
│  ▓▓▓▓░░░░░░  │  지원 직무 [        ]  회사 이름·선택 [     ] │
│  1.2/3.1GB   │  ─────────────────────────────────────────── │
│  약 4분 남음   │  이력서                        2,480자 추출됨 │
│  ──────────  │  [파일 올리기][저장본에서][직접 쓰기][붙여넣기] │
│  ■ 지원 정보  │  ┌─────────────────────────────────────────┐ │
│  ■ 이력서     │  │   PDF를 여기에 끌어다 놓으세요            │ │
│  □ 모델 39%   │  └─────────────────────────────────────────┘ │
│  □ 목소리     │                                               │
│  [모델 받는 중]│                                               │
└──────────────┴───────────────────────────────────────────────┘
      376px                        남는 폭
```

- 왼쪽 상황판은 **376px 고정**, 화면에 붙어 따라온다. 출근 장면 · 진행바 · 남은 시간 · 체크리스트 · 시작 버튼이 한 기둥에 선다.
- 체크리스트는 시작 버튼 **바로 위**에 둔다. 비활성 버튼과 미완료 항목이 붙어 있어야 이유가 읽힌다.
- 모델을 다 받으면 그 자리의 버튼이 `모델을 받는 중…`에서 노란 `면접 시작`으로 바뀐다. 자리는 그대로다.
- **1024px 아래에서는 상황판이 위로 올라가 가로로 눕는다.** 두 기둥을 억지로 세우지 않는다.
- 출근 장면을 376px 안에 넣을 때 **정수 배율**만 쓴다. 들어갈 배율이 없으면 장면 폭에 맞춰 상황판 폭을 조정한다 — 소수 배율로 줄이지 않는다(루트 `CLAUDE.md` 픽셀 규율).

### 입력 영역

- **2단계 화살표 전환을 없앤다.** 지원 정보와 이력서가 한 흐름으로 이어진다. 칸이 넷 이하라 나눌 이유가 없다.
- 트랙(회사 / 대입)에 따라 보이는 칸이 달라지는 현재 규칙은 그대로다.
  - 회사: 분야 · 지원 직무 · 회사 이름(선택) · 모집공고 링크(벤만)
  - 대입: 이름 · 나이 · 지원 대학 · 지원 학과
- 이력서 입력 넷을 **탭**으로 접는다: `파일 올리기` · `저장본에서` · `직접 쓰기` · `붙여넣기`. 한 번에 하나만 보인다.
  - 로그인 사용자는 `저장본에서`가 기본 탭이고, 탭 이름에 개수를 적는다.
  - 비로그인은 `저장본에서` 탭이 **아예 없다**(슬롯이 없다).
- 면접관 칩과 바꾸기, 힌트 켜기는 입력 창 **머리**로 올린다.

### 벤 조절 — 게임 설정 화면 어법 (2026-11-07 추가)

**벤을 고른 면접에서만** 나타난다. 무료 면접관에는 이 영역 자체가 없다.

- 면접관 줄에 `면접관 벤 [바꾸기] [성향 ▾]`를 두고, 누르면 입력 창 안에서 다섯 줄이 펼쳐진다. **기본은 접혀 있다** — 다섯 줄을 늘 펼쳐 두면 준비 화면이 설정 화면이 된다.
- 한 줄의 모양: `라벨  ◀ [눈금 셋] ▶  고른 값  한 줄 설명`. 눈금은 세 칸으로 끊어 그려 연속이 아님을 보인다.
- 머리에 **"시작하면 잠깁니다"**를 적는다 — 계약상 면접 중에는 바꿀 수 없다(턴·리포트가 저장된 값을 쓴다).
- `전부 기본값으로` 되돌리는 링크를 머리에 둔다.

#### 화면 라벨과 값 이름

API의 값 이름(`low`·`balanced`…)을 그대로 보이지 않는다. **무엇이 달라지는지**를 적는다.

| 화면 라벨 | API 키 | 세 칸 (굵은 것이 기본) | 고른 값 옆 한 줄 |
|---|---|---|---|
| 말투 | `warmth` | **날카롭게** · 보통 · 부드럽게 | 칭찬 없이 짚고 넘어갑니다 / 표준 말투입니다 / 격려하며 묻습니다 |
| 꼬리질문 | `followUp` | 적게 · **보통** · 많이 | 너무 짧을 때만 / 질문당 2개까지 / 근거가 안 보이면 파고듭니다 |
| 질문 성격 | `questionMix` | 직무 지식 · **고루** · 사람·동기 | 아는 것과 푸는 법을 / 한쪽으로 몰지 않습니다 / 협업·갈등·동기를 |
| 난이도 | `difficulty` | 기초 · **실무** · 심화 | 개념을 확인합니다 / 해 본 일을 묻습니다 / 왜 그걸 골랐는지까지 |
| 회사 이야기 | `companyWeight` | 적게 · **보통** · 많이 | 회사 소식 1개 / 1~2개 / 2~3개 |

#### 계약에서 끌어낸 규칙 셋

1. **다섯 칸이 전부 기본이면 `benSettings`를 아예 보내지 않는다.** 그래야 "설정을 안 보내면 지금 벤과 프롬프트가 글자까지 같다"는 계약이 유지된다. 바꾼 칸만 보내도 된다.
2. **회사 이야기 줄은 때때로 사라진다.** 입학 트랙이거나 회사 이름이 없으면 서버가 그 값을 무시한다 — 무시되는 칸을 고르게 두면 거짓말이다. 줄째로 빼고 네 줄만 보인다. 회사 이름을 지우면 그 자리에서 사라진다.
3. **자유 입력 칸을 만들지 않는다.** 고른 값만 보낸다 — 프롬프트 주입 경로를 열지 않는다.

#### 왜 세그먼트가 아니라 눈금인가

- 값 이름을 **한 번만** 적어 좁은 폭에 다섯 줄이 다 들어간다. 세 칸을 모두 적으면 390px에서 넘친다.
- `<input type="range" min="0" max="2">`를 쓰면 화살표 키·화면 낭독기가 **표준대로 거저 따라온다.**
- 레트로 게임의 설정 화면 어법이라 이 제품과 결이 맞는다. cw의 백엔드 spec도 "슬라이더 다섯 개"라고 썼다.

**약점은 안다** — 고르지 않은 값이 보이지 않는다. 고른 값 이름과 한 줄 설명을 늘 띄워 그 손해를 줄이고, 실제로 사람들이 다른 값이 있는 줄 모르는지는 demomo에서 본다(6절).

### 시작 영역 — 세 덩이

1. **벤 안내 묶음** — 외부 AI 고지 + 목소리 분석 동의 체크를 한 상자로 묶고, **벤일 때만** 띄운다. 문구는 `docs/terms/2026-11-03-terms.md`와 현재 운영 문구를 그대로 쓴다(루트 `CLAUDE.md` 8번).
2. **체크리스트** — 지원 정보 · 이력서 · 모델 · 목소리. 가로 한 줄.
3. **시작** — 버튼 하나. `목소리 없이 시작`은 버튼이 아니라 곁가지 링크로 내리고, 목소리가 아직일 때만 보인다. 에러는 버튼 아래 한 자리.

### 입력 칸 규칙

- 라벨은 **칸 위**에 둔다. 글자가 길어져도 칸이 밀리지 않고, 좁은 화면에서도 같은 자리다.
- 선택 항목은 라벨 옆에 `· 선택`을 흐리게 적고, 칸 테두리도 한 단계 흐리게 한다.
- 오류는 칸 **바로 아래 한 줄**. 공고 링크 경고가 지금 그 자리이므로 그대로 둔다.
- 안내문·동의 문구는 `--lh-read`(1.8)를 쓴다. 입력 칸 안의 글자는 그대로다.

## 6. 무회귀 · 롤아웃

- 계약 변경이 없어 단독 배포 가능하다.
- **`step`을 없애면서 잃기 쉬운 것**: 1단계가 안 찼을 때 2단계로 못 넘어가게 막던 규칙. 한 화면이 되면 그 잠금이 사라지므로, 시작 버튼의 `canStart`만으로 충분한지 확인한다.
- 이력서 탭으로 접으면서 **지금 보이던 저장본 목록이 숨는다.** 로그인 사용자에게는 그 탭이 기본이 되도록 해 체감이 나빠지지 않게 한다.
- 벤 동의 문구는 운영에 나가 있는 문장과 **한 글자도 달라지면 안 된다**. 옮기기만 한다.
- **벤 성향은 손대지 않으면 지금과 똑같아야 한다.** 다섯 칸이 전부 기본일 때 `benSettings`를 보내지 않는 것으로 보장한다. 이 조건이 깨지면 기존 벤 면접의 성격이 조용히 바뀐다.
- 성향 줄을 **접은 채로도 면접을 시작할 수 있어야 한다.** 펼치지 않으면 기본값이다.
- 배포 순서: 작업 PR → `dev` → demomo에서 **모델을 실제로 받아 보며** 확인 → `dev → main`.

## 8. 성공 기준

- 1440px에서 모델을 받는 동안 **스크롤 없이** 지원 정보와 이력서를 다 넣을 수 있다.
- 모델이 다 받아지는 순간 왼쪽 버튼이 그 자리에서 `면접 시작`으로 켜진다. 레이아웃이 움직이지 않는다.
- 이력서 탭을 바꿔도 창 높이가 요동치지 않는다.
- 1024px 아래에서 상황판이 위로 올라가 가로로 눕고, 입력은 그대로 쓸 수 있다.
- 벤을 고르면 외부 AI 고지와 목소리 동의가 한 상자로 뜨고, 무료 면접관에서는 그 상자가 **없다.**
- 출근 애니메이션이 정수 배율로만 들어간다(소수 배율 사용 0건).

### 벤 조절

- 무료 면접관을 고르면 `성향` 버튼과 다섯 줄이 **아예 없다.**
- 벤을 고르고 **아무것도 건드리지 않고** 시작하면, 요청 본문에 `benSettings` 키가 **없다**(네트워크 탭으로 확인).
- 한 칸이라도 옮기면 **옮긴 칸만** 담겨 나간다.
- 화살표 키로 다섯 줄을 오가며 값을 바꿀 수 있고, 화면 낭독기가 각 줄의 라벨과 현재 값을 읽는다.
- 입학 트랙을 고르거나 회사 이름을 비우면 **회사 이야기 줄이 사라진다.**
- 390px에서 다섯 줄이 각각 한 줄에 들어간다(값 이름이 잘리지 않는다).
- demomo에서 벤 면접을 **말투 `부드럽게`로 한 번** 완주해 면접관 말투와 리포트 말투가 실제로 달라지는지 본다(티켓 1장 소모).
