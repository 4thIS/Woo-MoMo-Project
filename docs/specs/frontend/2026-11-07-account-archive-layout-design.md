## 1. 목표 · 비목표

### 목표

- 내정보에서 **칸을 내용 길이에 맞추고**, 남는 자리를 실제로 알고 싶은 숫자로 채운다.
- 이력서 슬롯을 **칸으로** 보여 몇 칸이 남았는지 모양으로 알게 한다.
- 보관함 목록의 메타를 **열로 세워** 세로로 훑을 수 있게 한다.
- 보관함 상세를 모달에서 꺼내 **리포트 화면을 그대로 재사용**한다. 같은 내용을 두 레이아웃으로 그리는 일을 끝낸다.

### 비목표 (이번엔 안 함 / 후속)

- 계정 기능(가입 · 로그인 · 티켓 · 보관 한도 · 슬롯 개수)은 바꾸지 않는다.
- 보관함 **목록**은 모달로 남긴다. 상세만 화면으로 나간다.
- 가입일 · 총 면접 횟수는 **넣지 않는다.** 지금 서버가 주지 않는 값이다. 넣으려면 백엔드 요청이 선행한다(`@ssenu`).
- 계정 삭제(탈퇴) 화면은 이번 범위가 아니다. 안내 문장만 둔다.

## 3. 접근 제어 / 제약

### 내정보 — 세 덩이

```
┌──────────────────────────────────────────────────────────────┐
│ 내정보                                                  닫기  │
├──────────────────────────────────┬──────────┬───────────────┤
│ [초상 72]  이우진  26세  ●프리미엄  고치기 │ 남은 티켓 │ 보관함      │
│            leemonta9482@gmail.com │    3 장  │    9 개     │
│            면접 중에 쓰는 이름과 나이 │[티켓 더 사기]│ 무료는 5개까지│
├──────────────────────────────────┴──────────┴───────────────┤
│ 이력서 보관 — 면접 시작할 때 바로 꺼내 씁니다  [회사 2/6][대입 0/6]│
│ ┌────────────┐┌────────────┐┌ ─ ─ ─ ─ ─ ─ ┐                │
│ │신입 백엔드  ││포트폴리오용 ││     +        │                │
│ │2,480자      ││3,120자      ││  새로 쓰기   │                │
│ │[열기]   ··· ││[열기]   ··· ││  4칸 남음    │                │
│ └────────────┘└────────────┘└ ─ ─ ─ ─ ─ ─ ┘                │
├──────────────────────────────────────────────────────────────┤
│ 계정을 지우려면 메일로 알려 주세요              [로그아웃]      │
└──────────────────────────────────────────────────────────────┘
```

배열 규칙 넷:

1. **칸은 내용 길이만큼.** 이메일·이름·나이를 똑같이 3분의 1씩 나누지 않는다. 두 글자짜리 나이가 이메일과 같은 폭을 받으면 허전해 보인다.
2. **남는 자리는 숫자로 채운다.** 티켓·보관함처럼 **이미 있는 값만** 쓴다.
3. **이름 옆에 초상을 둔다.** 72px 한 덩이가 왼쪽을 잡아 글만 뜬 느낌을 없앤다. 지원자 캐릭터 스프라이트를 쓰고 **정수 배율**만 적용한다.
4. **숫자는 크게.** 티켓·보관함 수는 픽셀 글꼴 34px. 상자 하나를 숫자 하나가 채운다.

- 이름·나이는 평소에 **한 줄로 흐른다**(`이우진 · 26세 · ●프리미엄 · 고치기`). 고칠 때만 그 자리에 칸이 생기고, 폭은 이름 92px / 나이 44px이다. 보기 상태와 편집 상태의 **줄 높이와 초상 위치가 어긋나지 않아야** 한다.
- 이력서 슬롯은 3열 카드. 지우기는 카드 안 `···` 안으로 넣고 겉에는 `열기`만 둔다 — 되돌릴 수 없는 일이 한 번에 눌리지 않게 한다.
- 빈 칸은 점선 `+ 새로 쓰기` **하나만** 그리고 거기에 `n칸 남음`을 적는다. 빈 상자를 넷 늘어놓지 않는다.
- 좁은 화면(≤640px)에서 3열이 1열이 된다. 이때도 빈 칸은 하나만 보인다.
- 로그아웃은 바닥 오른쪽, 빨간 테두리. 평범한 버튼 모양으로 두지 않는다.

### 보관함 목록 — 열로 세운다

| 열 | 내용 |
|---|---|
| (초상) | 면접관 스프라이트. **정수 배율**로만 — 실제 프레임 크기를 보고 32 또는 48을 고른다 |
| 면접관 | 이름 + `녹음` / `프리미엄` 표식 |
| 갈래 | 회사 / 대입 |
| 지원 직무 | **제목 자리.** 회사 면접이면 직무(+회사), 대입이면 학과(+대학) |
| 문항 | 오른쪽 정렬 · 픽셀 글꼴 |
| 시간 | 오른쪽 정렬 · 픽셀 글꼴 |
| 날짜 | 오른쪽 정렬 · 픽셀 글꼴 |

- **지원 직무를 제목 자리로 올린다.** 같은 면접관으로 세 번 봤으면 지금은 날짜로만 구분되는데, 찾을 때 기억하는 건 "토스 백엔드 면접"이다.
- 숫자는 오른쪽 정렬 + 픽셀 글꼴이라 자릿수가 줄 맞아 세로 비교가 된다.
- 녹음·프리미엄은 **표식**으로 둔다. 문장에 끼워 넣지 않는다.
- `무료는 5개까지 · 오래된 것부터 밀려납니다`를 머리에 **상시** 적는다. 지금은 꽉 찼을 때만 나타나 그 전까지는 한도가 있는 줄 모른다.
- 640px 아래에서는 열이 서지 않는다. 지금 모양(두 줄)으로 돌아가되 **지원 직무를 첫 줄**에 올린다.

### 보관함 상세 — 모달에서 꺼낸다

- 목록(모달)에서 한 줄을 누르면 모달이 닫히고 **리포트 화면이 보관함 모드로** 뜬다.
- 레일 머리에 `← 보관함으로`와 그 면접의 제목(지원 직무 · 면접관 · 날짜)을 둔다.
- 레일의 목차 위에 탭 **`리포트` / `대화 전문`**. 기본은 리포트다. 같은 목차로 두 탭 모두 문항 이동이 된다.
- 액션은 레일 바닥에 `PDF` · `지우기`. 지우기 확인은 지금처럼 그 자리에서 묻는다.
- 녹음 재생바는 그 문항 **카드 바닥**에 붙는다. 지금처럼 대화 옆에 흩어 두지 않는다.
- 면접 중(`interview.phase === 'interview'`)에는 열 수 없다.

> **왜 모달을 유지하지 않는가.** 가독성이 나쁜 진짜 이유는 2열이 아니라 같은 내용을 두 레이아웃으로 그리고 있다는 것이다. 모달 안에서 탭으로 바꾸는 안은 레이아웃을 셋으로 늘리고, 긴 리포트용 목차·따라오는 머리를 한 벌 더 만들게 한다.

## 6. 무회귀 · 롤아웃

- 계약 변경이 없어 단독 배포 가능하다. 단 **보관함 상세는 리포트 spec 뒤에** 간다.
- **"한 번에 하나만 연다"는 모달 규칙**을 깨지 않아야 한다. 상세가 화면으로 나가면 모달은 닫히므로 오히려 지키기 쉬워진다. 내정보의 `···` 메뉴는 모달 안의 또 다른 띄우기이므로 이 규칙과 부딪히는지 확인한다.
- 보관함 상세가 화면이 되면 **뒤로 가기**로 목록에 돌아올 수 있어야 한다.
- 면접 중에는 상세를 열 수 없게 막는다.
- 이력서 슬롯 `···` 메뉴로 지우기를 옮기면서, 지우기 확인 단계를 **없애지 않는다**(되돌릴 수 없다).
- 배포 순서: 작업 PR → `dev` → demomo에서 저장된 면접(무료·벤 각 1건)을 열어 확인 → `dev → main`.

## 8. 성공 기준

### 내정보

- 이메일·이름·나이 줄에 빈 칸처럼 보이는 자리가 없다. 나이 칸이 이메일과 같은 폭을 받지 않는다.
- `고치기`를 눌러도 초상과 줄 위치가 **움직이지 않는다.**
- 이력서 칸이 둘 차 있고 `4칸 남음`이 적혀 있다. 빈 상자가 넷 늘어서 있지 않다.
- 지우기가 `···` 안에 있고, 눌렀을 때 확인을 한 번 더 묻는다.
- 640px에서 1열이 되고 빈 칸은 하나만 보인다.

### 보관함

- 목록에서 **지원 직무로** 면접을 찾을 수 있다. 같은 면접관 항목이 여럿이어도 구분된다.
- 문항 수와 시간이 자릿수로 줄 맞아 있다.
- 한도 안내가 꽉 차기 **전에도** 보인다.
- 한 줄을 누르면 리포트 화면이 뜨고, 레일·목차·따라오는 머리가 리포트 화면과 **같다.**
- `← 보관함으로`와 브라우저 뒤로 가기 모두 목록으로 돌아온다.
- 녹음이 있는 면접에서 재생바가 해당 문항 카드 바닥에 붙어 있다.
- 면접 중에는 보관함 상세가 열리지 않는다.
- 프론트 게이트 전부 통과.
