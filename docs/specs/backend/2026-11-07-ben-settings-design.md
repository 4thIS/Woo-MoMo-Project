# 벤 성향 설정 — 슬라이더 다섯 개로 면접관 조절

- 날짜: 2026-11-07
- 담당: 박찬우(@ssenu, backend)
- 기준: `docs/specs/backend/2026-10-23-ben-voice-baze-design.md`(벤 전체), `backend/app/llm/prompts.py`(계층 규율 경로)

## 1. 무엇을 · 왜

무료 면접관은 기본(데이빗)·압박(쥴리) 등 여럿인데 프리미엄 벤은 압박형 하나뿐이다. 벤 면접을 시작할 때 **성향을 다섯 축, 각 3단계로 고르게** 한다.

- 이번 작업은 백엔드(API·프롬프트)만 한다. 톱니바퀴·슬라이더 화면은 이우진의 새 디자인이 배포된 뒤 이슈로 요청한다.
- 설정을 보내지 않으면 지금 벤과 **프롬프트가 글자까지 같다**. 화면보다 먼저 배포해도 아무것도 바뀌지 않는다.

## 2. API — `POST /api/premium/interviews`에 `benSettings`(선택, additive)

```json
"benSettings": {
  "warmth": "low",            // 온화함: low(기본) | mid | high
  "followUp": "mid",          // 꼬리질문 깊이: low | mid(기본) | high
  "questionMix": "balanced",  // 질문 비중: technical | balanced(기본) | personal
  "difficulty": "practical",  // 난이도: basic | practical(기본) | advanced
  "companyWeight": "mid"      // 회사·공고 비중: low | mid(기본) | high
}
```

- 일부만 보내도 된다. 빠진 칸은 기본값. 정해진 값이 아니거나 모르는 키면 `422`(자유 입력 없음 → 프롬프트 주입 경로 없음).
- 저장: 기본값을 채운 다섯 칸을 면접의 `inputs_json` 안 `benSettings`로 둔다. 마이그레이션 없음. 이 칸이 없는 예전 면접은 기본값으로 읽는다.
- 면접 중에는 바꿀 수 없다(턴·리포트가 저장된 값을 읽는다). 응답 형태·티켓·하루 한도는 그대로.

## 3. 단계별 프롬프트

기본값 단계는 문장을 더하지 않거나 지금 문장을 그대로 쓴다.

| 축 | 단계 | 프롬프트 |
|---|---|---|
| 온화함 | low(기본) | 지금 벤 = 프론트 `personas.ts`의 `sharp`: 성격 문장·반응 "네."·리포트 말투 |
| | mid | `standard`: 성격 문장 없음, 반응 "네, 알겠습니다.", 리포트 말투 줄 없음 |
| | high | `gentle`: 부드러운 성격 문장, 반응 "네, 잘 들었습니다.", 격려하는 리포트 말투 |
| 꼬리질문 깊이 | low | 너무 짧을 때만, 질문당 1개(`gentle` 규칙 문장), 전체 1개 |
| | mid(기본) | 지금 규칙: 질문당 2개, 전체 3개 |
| | high | 근거·판단 이유가 안 드러나면 놓치지 않고 파고든다, 질문당 3개, 전체 3개 |
| 질문 비중 | technical | 자기소개 다음 질문 중 3개 이상 직무 지식·문제 해결(입학: 전공 지식·탐구) |
| | balanced(기본) | 없음 |
| | personal | 3개 이상 협업·갈등·가치관·지원 동기(입학: 인성·공동체 경험·지원 동기) |
| 난이도 | basic | 기초 수준 — 개념 이해와 기본 경험 확인 |
| | practical(기본) | 없음 |
| | advanced | 심화 — 선택 이유·대안 비교·한계와 개선까지 |
| 회사·공고 비중 | low | 회사 소식 질문 1개, 공고가 있으면 공고·회사 합쳐 1~2개 |
| | mid(기본) | 지금 규칙: 1~2개 / 합쳐 2~3개 |
| | high | 2~3개 / 합쳐 3~4개 |

- 전체 꼬리질문 상한은 3개를 넘지 않는다 → 면접 길이·Claude 비용·목소리 분석 상한(면접당 16) 그대로.
- "기술" 대신 "직무 지식"으로 써서 IT 밖 직무에도 맞게 한다.
- 회사·공고 비중은 브리핑이 있는 회사 트랙에서만 효과가 있다(브리핑 없음·입학 트랙은 무시). 회사명·공고 링크가 있으면 단계와 상관없이 지금처럼 조사한다.
- 질문 비중(질문의 종류)과 회사·공고 비중(질문의 출처)은 겹쳐 적용된다.
- 리포트 말투는 온화함을 따른다: 버전 1은 `report_instruction`의 말투 줄, 버전 2는 지시문의 말투 줄("압박 면접관답게 칭찬은 생략…")을 단계별 문장으로 바꾼다.

## 4. 구성

- `app/schemas.py`: `BenSettings`(Literal 다섯 칸, 기본값, `extra="forbid"`), `InterviewStart.benSettings: BenSettings | None`.
- `app/routers/premium.py`: 시작 때 `inputs["benSettings"]` 저장, 리포트 메시지에 온화함을 넘긴다.
- `app/llm/prompts.py`: `ben_settings(inputs)`(기본값 채우기), 축별 문장 표, `build_system`·`report_instruction`·`report_messages`·`report_messages_v2`가 설정을 따른다. `STANDARD_*`·`GENTLE_*` 문구는 `personas.ts`와 글자까지 같게 테스트로 묶는다.
- `docs/API.md`: `benSettings` 설명.

## 5. 테스트

- 기본값(설정 없음·빈 객체·기본값 명시)의 시스템 프롬프트·리포트 지시문이 변경 전 출력과 같다(변경 전 스냅숏 고정).
- 축·단계별로 들어가는 문장, 트랙별 문구, 브리핑 없을 때 회사·공고 비중 무시.
- 잘못된 값·모르는 키 → 422. 저장된 설정을 턴·리포트가 쓴다. 칸 없는 예전 면접은 기본값.
- `standard`·`gentle` 문구 프론트 일치.
- demomo: 화면이 없으므로 API로 벤 면접 2회 완주(기본값 1회, 온화함 high 포함 조합 1회) + 리포트 파싱 확인.

## 6. 하지 않는 것

- 설정 저장·프리셋, 면접 중 변경
- 질문 수 조절, 답변 시간 제한, 영어 면접
- 리포트·보관함에 설정값 표시
