# 벤 개인정보 가림 — 외부 AI로 보낼 때만 가리고, 돌아오면 되돌린다

- 날짜: 2026-11-08
- 담당: 박찬우(@ssenu, backend)
- 기준: 루트 `CLAUDE.md` "절대 하지 말 것" 8번(개인정보 등급), `docs/specs/backend/2026-10-23-ben-voice-baze-design.md`(벤 전체), `backend/app/llm/prompts.py`(계층 규율 경로)

## 1. 무엇을 · 왜

무료 면접관(로컬 LLM)은 이력서·대화가 기기를 떠나지 않는다. 프리미엄 벤은 Claude API로 이력서 전문과 대화가 나간다. 학습에 쓰지 않는다고 해도 **사람을 바로 알아볼 수 있는 정보는 아예 나가지 않게** 한다.

벤은 브라우저가 아니라 우리 백엔드가 Claude를 부른다. 그래서 백엔드에서 Claude로 보내기 직전에 개인정보를 `[이름1]`·`[전화1]` 같은 표시로 바꾸고, 응답을 사용자에게 보내거나 저장하기 전에 원래 값으로 되돌린다. 프론트·`/api` 계약은 바뀌지 않는다.

### 목표

- 이름·전화·이메일·주소·생년월일·주민번호·계좌/카드·개인 링크가 Claude로 나가지 않는다.
- 사용자 화면·DB에는 원래 값이 그대로 보인다(`[` 표시가 남지 않는다).
- 면접 질문 품질 유지: 학교·회사·프로젝트 이름, 나이, 지원 회사·직무, 성향 설정은 그대로 보낸다.

### 비목표

- 목소리 녹음 파일(Gemini)은 소리라 가리지 못한다. 녹음에서 나온 받아쓰기 글이 리포트 프롬프트로 Claude에 갈 때는 가린다.
- 개체명 인식 모델·외부 AI로 찾기는 쓰지 않는다(규칙 + 이미 아는 이름).
- 약관·안내 문구 변경(필요하면 이우진에게 이슈로 요청, 이번 범위 밖).

## 2. 어디서 가리고 되돌리나

```
브라우저 ──원문──▶ 백엔드 ──[가림]──▶ Claude
브라우저 ◀──원문── 백엔드 ◀──[되돌림]── Claude 응답
```

- 가리는 곳: Claude 호출 세 곳(면접 턴, 리포트 버전 1, 리포트 버전 2) 바로 앞. 시스템 프롬프트 블록 전부와 메시지 전부를 같은 가림 객체로 처리한다.
- 되돌리는 곳: 스트리밍 조각을 SSE로 내보내기 전, 그리고 DB 저장 전.
- DB에는 지금처럼 원문을 저장한다. 표시↔원래 값 짝은 저장하지 않고 호출마다 다시 만든다(새 개인정보 저장소 없음).
- 번호: 한 호출 안에서 시스템 블록 → 메시지 순서로 처음 나온 차례대로 매긴다. 대화는 뒤에 붙기만 하므로 앞 번호가 바뀌지 않고, 이력서가 든 시스템 블록은 매 턴 글자까지 같아 프롬프트 캐시가 그대로 맞는다.
- 벤에게 알림: 가림이 켜져 있을 때만 이력서 블록의 `DATA_NOTICE` 다음 줄에 "`[이름1]` 같은 표시는 가린 개인정보이며 그대로 써도 되고 원래 값을 추측·질문하지 않는다"를 붙인다. 꺼져 있으면 프롬프트가 지금과 글자까지 같다. 프론트 일치 테스트(`test_prompt_parity.py`)가 비교하는 문구는 건드리지 않는다.

## 3. 무엇을 어떻게 찾나 — 확실한 것만

| 표시 | 찾는 법 | 잘못 잡기 막기 |
|---|---|---|
| `[이름N]` | 아는 이름: 가입 이름(`users.name`), 입학 면접 `admission.name`, 이력서의 "이름·성명·Name:" 줄 | 2글자 이름은 앞에 한글이 붙어 있으면 건너뜀. 성 뺀 이름(3글자 이름의 뒤 두 글자)은 뒤에 "님·씨"가 붙을 때만. 영문 이름은 대소문자 무시·단어 경계 |
| `[전화N]` | 휴대폰 `01x`(하이픈·점·공백 유무, `+82 10…`), 유선은 하이픈 있는 지역번호 모양 | 앞뒤가 숫자면 제외. 금액·통계 숫자 보존 |
| `[이메일N]` | 일반 이메일 모양 | — |
| `[주민번호N]` | 6자리-(1~8)6자리 | 앞뒤가 숫자면 제외 |
| `[생년월일N]` | "생년월일·생일·출생·Birth·DOB" 라벨이 있는 줄의 날짜 | 라벨 없는 날짜(프로젝트 기간·수상일) 보존 |
| `[계좌N]` | 카드 4-4-4-4, "계좌·은행·입금" 라벨이 있는 줄의 숫자열(하이픈 포함 10~16자리) | 라벨 없는 숫자열 보존 |
| `[주소N]` | ① 도로명 "○○시/도 ○○구/군 ○○로/길 12(-3)" (+ 같은 줄의 "○동 ○호") ② "주소·거주지·Address" 라벨 줄의 나머지 | 시·구까지만("서울 거주")은 보존 |
| `[링크N]` | 개인 페이지: github·gitlab·velog·tistory·네이버 블로그·notion·linkedin·instagram·brunch·medium 개인 주소, `*.github.io` | 회사·서비스 데모·논문 링크 보존 |

- 처리 순서: 주민번호 → 카드·계좌 → 전화 → 이메일 → 링크 → 생년월일 → 주소 → 이름(긴 모양 먼저, 겹치는 구간은 먼저 잡은 쪽).
- 이미 있는 `[…N]` 표시 안은 건드리지 않는다.
- 같은 값은 같은 표시: 숫자류는 숫자만, 이메일·링크는 소문자로 비교한다.
- 가리는 곳: 이력서, 시스템 프롬프트의 입학 면접 이름(나이·대학·학과 보존), 대화의 사용자·벤 발언, 리포트 지시문에 붙는 받아쓰기 글.
- 알려진 한계: 이력서 속 다른 사람 이름(추천인·팀원), 라벨 없는 생년월일·계좌번호.

## 4. 되돌리기

- 면접 턴(스트리밍): 조각 끝에 `[`로 시작하는 표시 앞부분일 수 있는 짧은 꼬리(10자 이하)가 있으면 다음 조각과 합칠 때까지 붙잡아 둔다. 끝나면 남은 꼬리를 내보낸다. 종료 문장 판정은 되돌린 글로 한다.
- 리포트 버전 1·2(JSON 출력): 값을 넣을 때 JSON 문자열 이스케이프를 한다(`"`·`\`·줄바꿈이 있어도 JSON 유효). 저장되는 `report_raw`와 버전 2 파싱·검증은 되돌린 글로 한다.
- 모르는 표시(Claude가 지어낸 `[이름3]` 등)는 그대로 둔다.

## 5. 실패 처리 · 설정

- 가리기 단계에서 예상 못 한 예외가 나면 **원문을 보내지 않고** Claude를 부르지 않은 채 그 요청을 `claude_error`로 끝낸다(다시 시도 가능, 실패한 턴은 기록하지 않는 지금 규칙 그대로).
- 설정 `BEN_PII_MASK`(기본 켜짐). 질문 품질 문제가 생기면 `.env`로 끌 수 있다. 끄면 프롬프트·동작이 지금과 같다.
- 로그: 호출마다 종류별 가린 개수만(`pii masked name=1 phone=1 …`). 값은 남기지 않는다.

## 6. 계약 · 영향

- `/api`·SSE 이벤트·DB 스키마·`docs/API.md`·프론트: 변경 없음.
- `backend/app/llm/pii.py`(새), `routers/premium.py`(호출 세 곳), `llm/prompts.py`(`build_system`에 가림 알림 줄, 꺼져 있으면 그대로), `config.py`(`BEN_PII_MASK`), `deploy/docker-compose.yml`·`deploy/README.md`(설정 이름).
- 계층 규율: `prompts.py`를 바꾸므로 demomo 벤 완주 + 리포트 파싱 확인, PR에 전후 비교.

## 7. 테스트

- 규칙별 잡아야 할 것·잡으면 안 되는 것(2글자 이름 단어 중간, "지원자", 라벨 없는 날짜, 금액, 회사 링크, "서울 거주").
- 같은 값 같은 표시, 번호가 턴이 늘어도 그대로, 시스템 블록이 매 턴 글자까지 같음.
- 스트리밍: 표시가 두세 조각으로 잘려도 되돌림, 끝 꼬리 내보냄, 표시가 아닌 `[`는 그대로.
- 리포트: `"`가 든 값을 넣어도 JSON 유효.
- 라우터: 가짜 Claude가 받은 내용에 이력서의 이름·전화·이메일 원문이 없고, SSE·DB에는 원문이 있음. 가리기 예외면 Claude 호출 0회. 설정을 끄면 지금과 같은 프롬프트.
- 기존 `ben_prompts_before_settings.json` 비교 테스트는 설정을 끈 상태 또는 개인정보가 없는 입력으로 계속 통과해야 한다.

## 8. 성공 기준 (demomo)

- 이름·전화·이메일·주소·깃허브 링크가 든 가짜 이력서로 벤 1회 완주 + 리포트(버전 2) 확인.
- 화면·리포트에 원래 값이 자연스럽게 보이고 `[` 표시가 없음. 질문 품질 전후 비교를 PR에 붙임. 관리자 사용량에서 오류가 늘지 않음.
