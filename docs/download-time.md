# 모델 다운로드 시간 실측 (2026-10-19)

> 외부 전문가 멘토링(2026-10-12) 보완사항 2 — "다운로드 시간 실측과 단계적 로딩 등 진입 장벽 완화를 검토할 것"에 대한 측정 기록.

## 무엇을 받는가

`backend/data/manifest.json` 기준.

| 항목 | 크기 |
|---|---|
| 모델 Gemma 4 E4B (`.litertlm`) | 2.97 GB |
| 모델 Gemma 4 E2B (GPU 메모리 부족 시 자동 폴백) | 2.01 GB |
| 목소리 Supertonic 3 (ONNX 4개 + 설정 + 보이스 1종) | 399 MB |
| **합계 (E4B + 목소리)** | **3.37 GB** |
| 합계 (E2B + 목소리) | 2.41 GB |

벤(프리미엄)을 고르면 모델을 받지 않는다(`stores/model.ts`의 `llmSkipped`). WebGPU가 없는 기기에서는 목소리도 받지 않는다 — 합계 0 GB.

## 측정 방법

모델이 실제로 놓인 Hugging Face CDN에 Range 요청으로 100MB를 받아 3회 측정했다. 브라우저도 같은 URL에서 같은 방식으로 받는다(`services/modelCache.ts`).

```bash
curl -sL -H "Range: bytes=0-104857599" -o /dev/null \
  -w "%{size_download} %{time_total} %{speed_download}" "$MODEL_URL"
```

| 회차 | 받은 양 | 걸린 시간 | 속도 |
|---|---|---|---|
| 1 | 105 MB | 13.5초 | 7.77 MB/s (62 Mbps) |
| 2 | 105 MB | 13.8초 | 7.60 MB/s (61 Mbps) |
| 3 | 105 MB | 14.9초 | 7.06 MB/s (56 Mbps) |
| **평균** | | | **7.48 MB/s (60 Mbps)** |

## 회선별 예상 시간

측정한 7.48 MB/s를 기준으로, 나머지는 회선 실효 속도로 환산했다.

| 회선 | 실효 속도 | E4B + 목소리 (3.37GB) | E2B + 목소리 (2.41GB) |
|---|---|---|---|
| **실측(측정 환경)** | 7.5 MB/s | **7분 30초** | 5분 21초 |
| 기가 유선 | 62.5 MB/s | 53초 | 38초 |
| 일반 유선 100Mbps | 12.5 MB/s | 4분 29초 | 3분 12초 |
| 공용 와이파이 50Mbps | 6.3 MB/s | 8분 58초 | 6분 25초 |
| LTE 20Mbps | 2.5 MB/s | **22분 27초** | 16분 2초 |

## 읽은 것

- **기가 유선에서는 1분이 안 걸린다.** 시연·심사 환경에서는 대기가 문제되지 않는다.
- **집·학교 회선(50~100Mbps)에서 4~9분.** 출근 애니메이션이 버텨 주는 구간이다.
- **LTE에서 22분.** 사실상 이탈한다. 휴대폰은 애초에 모델을 올리지 못하므로(WebGPU 없음) 이 경우는 벤으로 보내는 것이 맞다 — 2026-10-19 작업에서 그 길을 열었다.
- 목소리 399MB는 전체의 12%다. 받는 순서를 미루면 **첫 질문까지가 실측 회선에서 53초, LTE에서 2분 40초 빨라진다.**

## 반영

- 진행 바에 받는 속도와 남은 시간을 함께 표시한다(남은 시간은 분 단위로 반올림 — 회선이 흔들릴 때 초가 널뛰면 없느니만 못하다).
- 랜딩 첫 화면에 권장 사양과 필요 용량을 먼저 알린다.
- 휴대폰·태블릿은 배너로 알리고, 벤(서버 추론)으로 가는 길을 연다.

## 다시 재려면

```bash
URL=$(python -c "import json;print(json.load(open('backend/data/manifest.json'))['url'])")
for i in 1 2 3; do
  curl -sL -H "Range: bytes=0-104857599" -o /dev/null -w "%{speed_download}\n" "$URL"
done
```

매니페스트의 모델이 바뀌면 크기도 바뀌므로 표를 다시 계산한다.
