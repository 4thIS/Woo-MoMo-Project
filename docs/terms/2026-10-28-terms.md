# 모두의 모의면접 약관 (버전 2026-10-28)

> 가입 화면의 [보기]에 그대로 보여 주는 간략판이다. 버전을 바꾸면 새 파일을 만들고 백엔드 `TERMS_VERSION`을 함께 올린다.

## 1. 이용약관 (필수)

1. **서비스** — 모두의 모의면접(이하 "서비스")은 AI 면접관과 모의면접을 하고 피드백 리포트를 받는 연습용 서비스입니다.
2. **계정** — 가입한 이메일과 비밀번호는 본인이 관리합니다. 다른 사람의 이메일로 가입하거나 계정을 빌려주면 안 됩니다.
3. **AI 피드백** — 면접 질문과 리포트는 AI가 만든 참고 자료입니다. 실제 채용 결과를 보장하지 않으며, 틀린 내용이 있을 수 있습니다.
4. **프리미엄** — 프리미엄 면접관(벤)은 티켓 1장으로 면접 1회를 진행합니다. 결제와 환불은 결제 화면에 안내한 기준을 따릅니다.
5. **금지 행위** — 서비스를 자동으로 대량 호출하거나, 다른 사람의 개인정보를 이력서로 올리거나, 서비스 운영을 방해하는 행위를 할 수 없습니다.
6. **변경·중단** — 서비스는 학생 프로젝트로 운영되며, 기능이 바뀌거나 사전 안내 후 중단될 수 있습니다.

## 2. 개인정보 수집·이용 (필수)

| 항목 | 내용 |
|---|---|
| 수집하는 정보 | 이메일, 비밀번호(복원할 수 없게 암호화해 저장), 이름, 나이(선택), 사용자가 저장한 이력서·면접 기록·리포트·답변 녹음 |
| 이용 목적 | 로그인, 이력서·면접 기록 보관과 다시 보기, 프리미엄 면접 진행 |
| 보관 기간 | 사용자가 지우거나 탈퇴를 요청할 때까지. 요청하면 지체 없이 지웁니다 |
| 외부로 보내는 경우 | 프리미엄 면접관(벤)의 대화 → Anthropic(Claude API) / 목소리 분석에 동의한 벤 면접의 답변 녹음 → 학교 BAZE 게이트웨이 경유 Google Gemini(분석 후 서버의 녹음은 바로 삭제) / 가입 인증번호 메일 → 메일 발송 서비스 |
| 로그인하지 않으면 | 이력서·대화·리포트가 사용자의 브라우저를 떠나지 않습니다(브라우저 음성 인식 제외) |

동의하지 않으면 가입할 수 없습니다. 로그인하지 않고 무료 면접은 그대로 이용할 수 있습니다.
