# 질문·피드백 품질 평가 요청 (전문가용)

> 외부 전문가 멘토링(2026-10-12) 보완사항 3 — "질문·피드백 품질의 정량 평가(전문가 검토, 만족도 조사)를 추가할 것".
> 이 문서는 **검토자에게 그대로 보내는 양식**이다. 샘플을 채운 뒤 전달한다.

## 보내기 전에 채울 것

1. demomo(https://demomo.ssenu.cloud)에서 면접을 **3회** 완주한다.
   - 회사 트랙 2회(분야·직무를 서로 다르게), 대입 트랙 1회
   - 이력서는 실제 것 대신 가상의 것을 쓴다 — 검토자에게 개인정보가 가지 않는다
2. 각 회차의 **질문 전문**과 **리포트 전문**을 아래 샘플 칸에 붙인다. 리포트 화면의 "복사" 버튼이 통째로 떠 준다.
3. 검토자에게 이 문서와 함께 보낸다. 익명 처리할 것: 이름·학교·회사명.

## 검토자께 드리는 안내

모두의 모의면접(MoMo)은 브라우저 안에서 도는 AI가 이력서를 읽고 면접관 역할을 하는 서비스입니다. 점수를 매기지 않고 **문항별 피드백**만 드립니다.

아래 샘플은 실제로 생성된 질문과 리포트입니다. 다음 네 가지만 봐 주시면 됩니다. 각 항목 1~5점(1=전혀 아니다, 5=매우 그렇다)과 한 줄 근거를 적어 주십시오.

| 항목 | 묻는 것 |
|---|---|
| **A. 질문의 적합성** | 이력서·직무에 비추어 실제 면접에서 나올 법한 질문인가 |
| **B. 꼬리질문의 타당성** | 답변을 듣고 더 캐묻는 지점이 적절한가 |
| **C. 피드백의 구체성** | "좋았습니다" 같은 말 대신, 무엇을 어떻게 고치라고 하는가 |
| **D. 사실 왜곡 여부** | 지원자가 하지 않은 말을 했다고 하거나, 없는 경력을 지어내지 않는가 |

마지막으로 한 가지만 더 여쭙습니다.

> **이 리포트를 받은 지원자가 다음 면접에서 다르게 행동할 만한 지점이 하나라도 있었습니까?** (예/아니오 + 그 지점)

## 회수 후 — 우리가 정리할 것

- 항목별 평균(A~D)과 최저 점수를 받은 항목
- "사실 왜곡"(D)에서 4점 미만이 하나라도 나오면 **프롬프트 수정 대상**이다. 이 항목만은 평균이 아니라 최저값으로 본다 — 한 번이라도 없는 경력을 지어내면 신뢰가 무너진다
- "행동이 달라질 지점"에 아니오가 많으면 피드백이 일반론에 머무는 것이다
- 결과는 발표 자료의 "품질 검증" 절에 평균 점수와 검토자 수로 싣는다

## 함께 받을 것 — 사용자 만족도

전문가 검토와 별도로, 실제 사용자 만족도는 **구글 폼**으로 받는다(서비스에 수집 기능을 넣지 않는다 — 비로그인 사용자의 데이터를 서버로 보내지 않는다는 원칙이 있다). 리포트 화면과 부스 현수막에 QR을 둔다.

폼 문항(5개, 1분):

1. 어떤 면접을 보셨습니까? (회사 / 대입)
2. 질문이 실제 면접에서 나올 법했습니까? (1~5)
3. 피드백이 구체적이었습니까? (1~5)
4. 다음에도 쓰시겠습니까? (예/아니오)
5. 한 가지만 고친다면? (주관식)
