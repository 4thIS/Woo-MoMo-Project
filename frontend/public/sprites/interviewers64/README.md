# 면접관 스프라이트 (64px 책상 구도, 실제 프레임 92×92)

PixelLab 캐릭터 파이프라인으로 만든 면접관 에셋. 기존 `../interviewers/`(32×32, 의자 구도)와 공존하며,
화면 전환은 별도 작업으로 한다.

## 구성

| 폴더 | 역할 | 동작 |
|---|---|---|
| `m1` | 온화한 남성 (40대, 회색 재킷) | idle · question_in / question / question_out · watch · lookside · armscross |
| `m2` | 압박형 남성 (50대, 흰머리·안경) | 〃 |
| `f2` | 압박형 여성 (50대, 단발·안경) | 〃 |
| `f3` | 중립 여성 (20대 후반, 포니테일) | 〃 |
| `sl` | 왼쪽 배석자 (얼굴 그림자) | left_idle · left_pageflip |
| `sr` | 오른쪽 배석자 (얼굴 그림자) | right_idle · right_writing · right_pentap |

가운데 자리에는 `m1`·`m2`·`f2`·`f3` 중 하나가 앉고, 양옆은 항상 `sl`·`sr`이다.
폴더 이름은 캐릭터 코드이며, 어떤 면접관 페르소나에 어느 캐릭터를 쓸지는 아직 정하지 않았다.

## 형식

- 가로 스프라이트 시트, 프레임당 **92×92**, 8fps 기준
- 폴더마다 `manifest.json`: `{"center_idle": {"file": "center_idle.png", "frames": 16, "w": 92, "h": 92}, ...}`
- 최상위 `manifest.json`은 폴더별 목록을 한데 모은 것

## 질문 동작은 세 클립이다

말하는 동안 한 클립을 반복하면 종이를 계속 들었다 놨다 한다. 그래서 나눴다.

| 클립 | 재생 |
|---|---|
| `center_question_in` | 말을 시작할 때 1회 — 책상의 종이를 집어 가슴 높이로 든다 |
| `center_question` | 말하는 동안 반복 — 종이와 손은 고정, 시선과 입만 움직인다 |
| `center_question_out` | 말을 마칠 때 1회 — 종이를 내려놓고 양손을 깍지 낀다 |

세 클립의 이음새 포즈를 맞춰 두었으므로 이어 붙여도 손 위치가 튀지 않는다.

## 알려진 제약

- 캐릭터를 따로 등록해 각자 책상을 그린 탓에, 셋을 나란히 붙이면 **책상 상판 높이·색이 미세하게 어긋난다.**
  후처리로 통일하는 작업은 별도로 진행한다.
- 프레임 수가 동작·캐릭터마다 다르다(8~28). `manifest.json`의 `frames`를 읽을 것.
- 기존 32×32 세트에 있던 `center_nod`는 만들지 않았다. 좋은 답변 반응 연출을 쓰지 않기로 했다.
