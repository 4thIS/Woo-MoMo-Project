# 스프라이트 품질 검사

생성 모델이 만든 프레임의 결함을 숫자로 잡는다. 통과한 것만 리포에 넣는다.

    python check.py ../../public/sprites/commute/m1

| 검사 | 기준 |
|---|---|
| 시트 크기 | manifest의 `w`×`frames`, `h`와 일치 |
| 캐릭터 흔들림 | 프레임 간 바운딩박스 **같은 엣지끼리** 이동이 6px 이하 |
| 고립 픽셀 | 사방이 투명한 1px 점 0개 |
| 팔레트 이탈 | 첫 동작에 없던 색 2종 이하 |

문제가 있으면 exit 1. 재생성(seed 변경)하거나 후처리로 고친 뒤 다시 돌린다.

## 기준선

면접관 92×92 세트(`interviewers64/m1`)로 잰 값 — 정면 고정이라 이 정도가 "정상"이다.

    center_idle      16프레임  흔들림 (0, 0)  고립 0  색 40
    center_armscross 28프레임  흔들림 (0, 3)  고립 0  색 50

걷기는 발·팔이 움직여 세로 흔들림이 이보다 크다. 가로는 제자리걸음이라 작아야 한다.
